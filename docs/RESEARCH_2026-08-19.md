# 2026-08-19 実装調査メモ

## 翻訳

Google Translate の Web ページ URL (`translate.google.com/translate?...`) を WebView で直接開く方式は CAPTCHA の対象になり、ページ翻訳機能として不適切である。Google ML Kit のオンデバイス翻訳を利用し、WebView で取得したテキストノードへ結果を戻す方式に変更する。

Google の公式 ML Kit ドキュメントによると、Translation API は 50 以上の言語でオンデマンドの端末内モデルを利用でき、Android API 23 以上を対象に `com.google.mlkit:translate:17.0.3` を導入する。必要なモデルは初回のみ取得し、翻訳完了後に Translator を close する。日本語を目標言語に固定し、言語識別には `com.google.mlkit:language-id:17.0.6` を使用する。

- https://developers.google.com/ml-kit/language/translation/android
- https://developers.google.com/ml-kit/language/identification/android

## Adblock

AdGuard の公式フィルタは Base、Tracking Protection、Mobile Ads、Japanese を初期セットにする。Japanese Filter Plus と同じ用途の追加重複リストは初期導入しない。uBlock Badware は本アプリの現在の単純な URL ルールサブセットでは正確に評価できないため、今回の標準セットから除外する。

AdGuard の公式配布 URL とヘッダーには 10 日の更新頻度が示される。アプリは端末内で 7 日ごとに HTTPS 経由で更新を試み、失敗時は既存の成功済みリストを保持する。

- https://adguard.com/kb/general/ad-filtering/adguard-filters/
- https://filters.adtidy.org/extension/chromium/filters/2.txt
- https://filters.adtidy.org/extension/chromium/filters/3.txt
- https://filters.adtidy.org/extension/chromium/filters/11.txt
- https://filters.adtidy.org/extension/chromium/filters/7.txt

## Fulguris

Fulguris の公開ソースは拡張した ABP/AdGuard ルールを管理し、フィルタ更新を月次で抑制する実装を持つ。本アプリは完全な ABP 実装ではないため、対応できる URL 規則だけを安全に取り込む。Fulguris のリポジトリ上ではページ翻訳機能の実装は確認できなかったため、翻訳は同ブラウザの WebView 画面遷移を模倣せず、端末内 ML Kit を採用する。

- https://github.com/Slion/Fulguris

## 動画と暗色化

動画ページ（YouTube と Google 動画検索）にはページ全体を CSS 反転する暗色化を重ねない。WebView の透明背景を禁止して常に黒を設定し、ページ開始時にも黒のベース層を維持する。Google 動画検索内の iframe 再生が音声だけになる問題は、親ページへの DOM フィルタおよび暗色 CSS が iframe を変形することを避け、WebView の標準メディア描画を優先する。

## セキュリティ

フィルタ URL と自動更新は HTTPS のみを許可する。署名鍵、パスワード、GitHub Actions Secrets の値はこの文書・ソース・ログに保存しない。
